# Phase 3 详解：目标期刊评估

## 核实清单（每一项都要独立交叉印证，不要只信一次检索）

1. **分区**：用户要求的分区体系（如中科院分区）的**当年版本**里，该刊的确切大类+小类分区。注意某些分区体系会改版、换名、或某年起停更改由其他机构接手——检索时留意这类信号，不确定就标"待确认"并附检索到的原话，不要脑补成确定结论。
2. **影响因子、JCR 分区、年发文量、审稿周期、OA/APC**：多个来源交叉核对，出现冲突时如实并列标注"三源冲突"而不是选一个假装确定。
3. **范围契合度**——这是最容易被高估的一项。不要只判断"这个学科方向听起来对不对"：
   - 尝试获取该刊官方公布的 Aims and Scope **原文**（哪怕只是摘要转述），逐句核对你的论文框架是否真的落在范围内。
   - **跨学科论文尤其要小心**：比如"用某学科的实验/记录数据做产业经济学分析"，很多学科期刊的公开范围明确只覆盖本学科内容，不接受这类论文，即使数据来源相同。
   - 如果范围原文获取不到，如实标注"待确认"，并在决策文件里写清楚这是一个未消除的风险，而不是含糊带过。
4. **可发表性证据**：检索该刊近 2–3 年发表的、**主题最相近**的论文（不是学科相近，是问题框架相近），每篇给完整引文（作者/年份/题名/期刊/卷期页/DOI）。找不到同类先例本身就是一个需要在决策文件里正面记录的风险信号。
5. **格式规范**：文章类型与字数上限、摘要结构与字数、关键词数、是否需要 Highlights/Graphical Abstract、章节结构与命名顺序、图表规范（分辨率/格式/彩色费用）、参考文献格式（**必须给出至少一条该刊真实论文的完整引用格式示例**，不要凭记忆编造格式）、单位与统计报告要求、声明部分（数据可用性/利益冲突/作者贡献/资助/致谢）、投稿系统。

## 常见陷阱

- **把"听起来对口"当成"范围契合"**：例如一个以某类记录数据为基础但实质是"测量/监管经济学"问题的论文，投给纯该学科技术期刊，即使数据来源同源，也可能因范围不符被 desk reject。范围核实不能省。
- **只查一次就下结论**：分区、影响因子经常有多个第三方站点给出不同数字（尤其分区体系改版过渡期），必须交叉印证并如实报告冲突。
- **参考文献格式凭印象编造**：不同期刊的 author-date/编号制、多作者简写规则（"et al." vs 列全部作者）、卷期页格式差异很大，务必找到该刊真实发表论文的引用样例照抄格式，而不是套用你熟悉的另一本期刊的格式。

## 决策产出

`plan/03_target_journal.md`：候选期刊对比表（分区/IF/契合度/格式负担/审稿周期/风险）、最终选择（首选+2 备选）及理由、对论文定位/标题/摘要的针对性调整建议。**如果首选期刊的范围契合度存疑，必须在这里明确写出应对策略**（例如：调整论文的叙事外壳、或改选范围更宽但分区可能不完全匹配用户要求的备选期刊，并向用户说明这个取舍）。

`plan/04_format_spec.md`：完整撰写规范清单，每条注明来源（检索到的官方原话或 URL），不确定项标"待确认"。这份文件是 Phase 4/5 反复对照的基准，务必详尽。
