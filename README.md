# 桐城市范岗镇单季稻"3414"肥料效应田间试验

依据 2025 年桐城市范岗镇新西村孙庄组单季稻"3414"肥料效应田间试验原始资料，
整理成可投《安徽农业科学》《安徽农学通报》等同类期刊的中文论文。

## 目录

| 路径 | 说明 |
|---|---|
| `稿件/桐城市范岗镇单季稻3414肥料效应田间试验.docx` | **投稿用正文**（含中英文摘要、7 张三线表、图 1、26 条参考文献） |
| `稿件/…（排版预览）.pdf` | 由 docx 转换的排版预览，便于快速查阅 |
| `稿件/图1_单因素肥料效应.png` | 图 1 源文件（600 dpi） |
| `分析/compute.py` | 主计算脚本：产量换算、丰缺评价、边际效益、相关分析 |
| `分析/fit.py`、`分析/fit2.py` | 肥料效应方程拟合（三元二次、一元二次、线性加平台） |
| `分析/fig.py` | 图 1 绘制脚本 |
| `分析/data.json` | 全部计算结果（正文与表格数值均来源于此） |
| `分析/content.js` | 论文文字源文件（含引用键与上下标标记） |
| `分析/refs_data.json`、`分析/refs.js`、`分析/mkrefs.js` | 参考文献结构化字段与 GB/T 7714—2015 著录生成 |
| `分析/build.js` | 由 content.js + data.json + refs.js 生成 docx |

## 复现

```bash
pip install numpy scipy matplotlib
npm install docx
cd 分析
python3 compute.py        # 生成 data.json
python3 fig.py            # 生成 fig1.png
node mkrefs.js refs_data.json > refs.js
node build.js ./refs.js manuscript.docx
```

## 数据说明

原始资料中正文叙述的 2 水平施肥量（N 12、P2O5 6、K2O 8 kg/667m²）与表 1 所列
（N 18、P2O5 12、K2O 15 kg/667m²）不一致。表 1 各水平满足 1 水平 = 0.5×2 水平、
3 水平 = 1.5×2 水平的"3414"设计关系，故以表 1 为准，折合
N 270、P2O5 180、K2O 225 kg/hm²。

原始资料的肥料效应方程与"最佳经济产量 680.3 kg/667m² 高于最高产量 550.1 kg/667m²"
互相矛盾，已按试验实测产量重新拟合，结果见 `分析/data.json`。
