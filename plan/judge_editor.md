## 〇、编辑的总体印象（先说结论）

四份提案的共同优点是罕见的：**全部核心统计量已在现有数据上实际跑通**，没有一份依赖"设想中的田间试验/农户问卷"。这在我收到的稿件里属于前 10%。四份提案也都主动披露了负面事实与失败检验，这在中国作者的投稿中同样少见，是加分项。

四份提案的共同弱点也很整齐：**因变量同源**（同一批审定公告解析结果），因此审稿人第一反应必然是"又一篇审定数据论文"（Lu24、Hang24、Zou24、Gong26 已占位）。谁能活下来，取决于**解释变量是否真的不同**，而不是结论是否漂亮。按这一标准：
- C 的解释变量（记录级试验通道）是**全新的、外部无人拥有的**；
- A 的解释变量（对照阶梯）是**把既有变量重新读出来的新尺度**，属方法学真增量；
- B 与 D 的解释变量（企业下游一体化）**是同一个**，且已被 Xie23 在同一家企业上部分占位。

另有一条必须说在前面的编辑判断：**四份提案不可能都投出去**。它们共用同一数据集与高度重叠的主分析层（A 用 n=1,256、B 用 n=1,353、C 用 n=878、D 用 n=1,349，仅窗口与筛选口径不同）。若同一团队在一年内向相近期刊投出三到四篇，任何负责任的编辑在 similarity check 阶段都会要求作者说明 companion paper 关系，处理不当会被判 salami slicing。**建议最多同时推进两篇，且互为 companion 并在投稿信中主动声明。**

### 2.2 读者兴趣与广度：结论是否只对中国读者有意义？

- **C 最好**：命题可以写成"当监管者把测量权下放给被监管者会发生什么"，医疗器械、食品认证、碳核查的读者都能读懂；中国只是提供了一个罕见的**同一份公告内并存自测性状与第三方测性状**的自然实验。这是四份里唯一能让非中国读者主动引用的框架。
- **A 次之**：链式对照方法可移植到任何采用"公告 + 具名对照 + 增产率"体例的国家与作物；且 38–45 kg/ha/yr 与 Seck23 全球均值 36.3 的吻合，是一个国际读者立刻能定位的锚点。这个"吻合"其实是 A 最有说服力的一句话，建议提到摘要更靠前的位置。
- **B/D 最弱**：结论高度依赖中国的审定门槛制度与订单粮食业态；国际读者读完会问"那么在美国/巴西呢"，而两份提案都无法回答。

### 2.3 「企业软文」风险 —— 这是我作为编辑最认真看的一条

按"企业是分析对象还是主角"排序（风险由低到高）：

1. **A（风险最低）**：荃银是九个谱系平台之一，占 1 节 + 1 图；论文即使删掉荃银部分仍然成立。这是处理单企业主线的**教科书式做法**。
2. **C（风险低，且手法最巧）**：荃银被安排成**反例**——"最典型的企业本应最多使用绿色通道，事实相反（60.2% vs 47.5%）"。企业在这里承担识别功能而非结论来源，读起来完全不像宣传。C 还把 2024 年报虚假记载与全文"自报 vs 第三方测量"主题呼应作为讨论收束，这是四份里最漂亮的一处写作设计。
3. **B（风险中等）**：负面事实处理得最充分（毛利率 3.56%→−1.31% 的完整序列、会计分解、保留意见与处罚），结论是"一体化改变了创新方向却没创造可占有租金"——这是一个**批判性**结论，不是软文。但两处仍需警惕：(i) 把隆平高科与荃银两家具名上市公司逐性状对比，加上 8 家同行财务截面表，整体观感接近 equity research；(ii) 订单粮食毛利率序列中 2021/2022 为推算值，把推算的公司分部数据当作论文序列使用，是投行尽调的习惯而非学术习惯，必须以区间呈现并在图注中标注。
4. **D（风险最高，必须修改）**：§8.7 把"育种端创造 2,150 万元加工价值 vs 下游毛亏 1,280 万元"作为 RQ3 的核心结论，推出"育种响应有效 + 财务执行失败，两者可分离"。**这恰好就是一家被 ST 的上市公司在投资者说明会上会讲的话。** 更麻烦的是这个数字的构造：把回归系数（+1.356 pp 整精米率）× 当年收购量折算成一个收益数字，隐含了"该优势可全额变现"的假设，而同一篇论文又证明它没有变现。编辑会读出"作者在替企业找补"。**建议 D 若保留此计算，必须把它降级为讨论中的一个量级注记，且同时给出"若按实际未实现变现则为 0"的对照，并明确这不是估计量而是算术演示。**

### 2.4 一般性：单一企业/单一国家的结论能否推广

缓解手段的有效性排序：
- **A 的九平台谱系对照最强**：不依赖缺失严重的申请人字段，全年份可用，把 n=1 变成 n=9，且每个平台样本量 20–143 条，足以支撑组间比较。这是四份里**唯一在数据结构层面而非修辞层面**解决一般性问题的设计。
- **C 的"反例"定位次之**：荃银不承担外部效度，承担的是机制排除功能；但 C 的一般性主要来自命题本身（自我认证），而非样本。
- **B 的四组主体设计（Public/OtherFirm/Longping/Winall）中等**：Longping 是唯一的"部分一体化"对照，n=58，单点对照撑不起"按一体化深度排序"这一核心主张。所谓"排序"目前只有 3 个点且中间点方向不一致（隆平垩白度不降），审稿人会质疑排序是事后叙述。
- **D 的 IntPeer（4 家母公司、83 条记录）最弱**，且编码依赖 Xie23 表 2 与年报分部行的主观判断；样外复制中垩白度方向相反，等于承认了机制的核心性状之一没有复制成功。D 自己在附录列出的"下一步三件事"（连续一体化强度面板、三重差分、同血缘对照）**正是审稿人会要求补的**——那就应该在投稿前做完，而不是列为下一步。

### 2.6 伦理与合规：数据来源与数据可用性声明

这是四份提案**共同的、尚未完全解决的**问题，我作为编辑会在第一轮就问：

1. **第三方汇编不可当作一手来源**。四份提案都写了"一手来源为农业农村部公告，GitHub 汇编 `he-zhui/Rice_QA` 仅为获取途径"——措辞正确，是可接受的。但**只有 A（R11）与 C（风险 4）承诺随机抽 50 条与官方公告原文逐字段复核并报告一致率**。B 与 D 没有这一步。**这一步是强制的**：没有它，Methods 里"一手来源为官方公告"就只是一句声明而非事实。建议四份统一执行，并把一致率写进正文 Methods（不是附录）。
2. **汇编的许可证（license）四份均未提及**。数据可用性声明要写"解析脚本 + 中间文件公开"，就必须确认原汇编的许可是否允许再分发衍生数据。若许可不明，正确写法是：公开解析脚本与字段字典、公开可复现的记录 ID 列表，而**不**直接再分发解析后的全表；或改为从农业农村部公告原文自行抓取重建。这一点必须在投稿前查清，否则 Data Availability 写不住。
3. **覆盖不全的披露**。四份都正确地把可靠窗口截到 2022 年，并声明不把"审定数量"作为结果变量（C 这一条写得最清楚）。可以接受。
4. **政治与合规敏感性**。C 涉及"自组织试验品种品质更差"，B/D 涉及证监会处罚。处理原则四份都对：只陈述公开事实、不做动机推断、不使用"造假/操纵"字样。C 把农业农村部自己的专项整治作为制度佐证，是最稳妥的写法，建议 B/D 借鉴。
5. 企业财务数据中的**推算值**（B 的 2021/2022 订单粮食毛利率、D 的 order_grain_share 序列）必须在表中以不同字体或标注区分观测值与推算值。学术期刊对这一点比财经媒体严格得多。

## 三、最佳方案

### **最佳方案 id：C（审定试验通道的自我认证不对称）**

理由（按权重排序）：
1. **可行性 9/10**：处理变量已从公告原文成功构造（解析成功率 100%），主结果、12 项稳健性、随机化推断、Manski 界、断点检验全部跑通。剩余工作是撰写与两项补算。四份里离"可以开写"最近。
2. **新颖性 9/10**：记录级试验通道变量在全部检索文献中从未被使用；最接近的 Xiang25 只观测时期不观测通道。"同一份公告内，申请人自测性状 vs 第三方测定性状"的方向不对称，是一个我此前没有见过的识别设计。
3. **fit 8/10**：JIA（农林 1 区）在任何分区口径下都超额满足硬指标，且两条腿（品种级分析 + 种业制度实证）都有本刊先例。
4. **rigor 8/10**：把两条 DID 设计的否决写进正文、把组内检验功效不足与省级复制失败主动前置——这是成熟作者的做法，会显著提高审稿人的信任度。扣分在于：**无法分离通道效应与申请人自选择**这一软肋无法靠现有数据补救，β 只能定义为"进入者构成效应"。
5. **企业处理最得体**：荃银是反例而非主角，负面事实与全文主题（自报 vs 第三方测量）在逻辑上闭环。

**次优：A（8.05）**，且 A 与 C 的组合是本项目最有价值的产出结构（见第五节）。

## 五、A + C 是否应合并？—— 编辑的判断

### 判断：**不合并成一篇，但必须合并成一个框架，作为 companion papers 前后脚投出；若被迫只写一篇，以 C 为骨架，把 A 的对照阶梯嫁接为其中一节，舍弃 DEA/前沿部分。**

**理由如下。**

首先必须承认提问者的直觉是对的：A 与 C 确实在追问同一个母问题——**"审定公告里的数字到底测量了什么"**。A 说"这把尺子的零点每几年就被换掉，所以跨期读数是假的"；C 说"这把尺子在 2016 年后有一半是被测量对象自己拿着的，所以跨主体读数也是有条件的"。把两者放在一起，确实构成一个比任何单篇都更有分量的命题：**中国品种审定记录是一套测量系统，而这套系统的零点漂移与测量权分配，共同决定了我们从中读出的"育种进展"**。这个框架如果成立，它比"某企业品种品质更好"重要一个数量级，也是四份提案中唯一可能进入方法学经典引用的东西。

**但一篇论文装不下。** 具体到编辑的操作层面：

1. **两个估计量的性质不同，方法节无法共用**。A 的估计量是一个**时间序列分解**（表观趋势 = 漂移 + 对照更替 + 当期优势），识别支点是"对照品种是唯一具有重复观测的基因型"；C 的估计量是一个**同年截面构成效应**，识别支点是"同年×同试验组×同对照内的通道对照"，且 C 明确声明它享有"同年内所有品种面对同一套政策"的免疫力。合并后，读者要在同一篇里理解两套完全不同的识别逻辑，Methods 会膨胀到 4,000 词以上。Rice Science 摘要上限 350 词、JIA 结构固定，都撑不住。

2. **图表清单会失控**。A 已规划 8 图 4 表，C 已规划 9 图 5 表，两者几乎没有可合并的图。压缩到 8 图，等于每个故事只剩 4 张图，两个故事都讲不完整。**"结论能否用一句话讲清楚"这一条会直接失分**——合并后的一句话必然是"审定数据有两个问题"，而"两个问题"在编辑听来就是"没有一个核心贡献"。

3. **读者群与期刊不同**。A 的读者是育种家与作物生理学家，关心"38 vs 75 kg/ha/yr 到底该信哪个"；C 的读者是农业政策与规制经济学读者，关心"开门放进来了什么"。Rice Science 不会欣赏 C 的规制经济学骨架，CAER/JIA 的经济学审稿人也不会耐心读 DEA-Malmquist。合并后无论投哪本，都有一半内容是审稿人不想读的。

4. **更要命的是：两者之间存在一处未解决的张力，合并会把它推到台面正中**。A 的分解把"表观趋势减去链式遗传增益"的残差全部命名为"试验体系非遗传漂移（+0.445 %/yr）"；而 C 证明 2017 年后新通道记录占比过半、且这些记录的自报增产率系统性偏高 +0.55 pp。**这意味着 A 的"漂移"里混着 C 的"通道构成效应"，两个数字在争夺同一份方差。** 分开写，A 只需把通道作为一项稳健性控制（见嫁接要素 6），并引用 companion paper；合并写，作者就必须当场给出一个把漂移进一步分解为"通道构成 / 试点变更 / 栽培改进 / 气候"的模型——而提案 A 自己已经明说"不声称能进一步分解"。**合并会制造一个作者无法兑现的承诺，这是审稿人最容易抓住的把柄。**

5. **荃银主线在合并版里会被稀释到消失**。A 中荃银占 1 节 1 图，C 中占 15% 篇幅；合并后两者都要压缩，荃银大概率只剩两三段。这与项目的硬约束（以荃银为主线）直接冲突。换句话说，合并后的论文会是一篇**更好的方法学论文，但不是本项目要写的那篇论文**。

**因此我的编辑建议是：**

- **Paper 1 = C**（投 JIA）：《Who Guards the Gate?》。在引言中用一段把"审定记录是一套测量系统"的大框架讲出来，并预告 companion paper 处理零点漂移问题。把 A 的对照阶梯作为**一个小节**（约 600 词 + 1 图）嵌入，专门用来把"自报增产率 +0.55 pp"这一 Manski 界下不稳定的结果救活。
- **Paper 2 = A**（投 Rice Science）：《Rotating checks conceal genetic gain》。**必须**把 C 的通道变量作为分解式中的一个显式控制项（否则"漂移"的解释站不住），并引用 Paper 1。同时我强烈建议 **A 砍掉 DEA/Malmquist 前沿部分**，只保留链式对照分解 + 九平台性状矩阵 + 荃银轨迹。理由：DEA 以"全生育期"为唯一投入、以抗性序数为产出之一，这个设定在作物科学审稿人眼里是有争议的（序数产出进 DEA、单投入的经济学含义、VRS 对离群值的敏感），而它并不是 A 的核心贡献；砍掉之后 A 的一句话论点从两句变回一句，图表从 8 图降到 5–6 图，全文的说服力会**上升**而不是下降。前沿部分可以单独成为第三篇或并入 Paper 1 的讨论。
- 两篇在投稿信中互相声明为 companion，并在 Methods 中共用同一份数据与解析脚本的公开链接。这样 similarity check 不会出问题，反而会被视为一个有纪律的研究计划。

**如果项目只能推进一篇**：选 C，并按上述方式嫁接 A 的阶梯。理由是 C 的 feasibility 与 novelty 都更高、desk reject 风险更低、荃银的角色安排更得体，而 A 最独特的那件东西（对照阶梯）体积小、可以整段搬进 C；反过来则不成立——C 的通道变量搬进 A，只能当一个控制变量，无法成为 A 的卖点。

## 六、B 与 D 应否合并或取舍

### 判断：**合并，且以 B 为骨架、D 为弹药；合并后作为本项目的第二优先级产出，排在 C 之后、与 A 并列或略后。绝不可分别投出。**

**为什么必须合并：**

B 与 D 的一句话论点几乎逐字相同——"当种企向下游延伸，加工品质进入收益函数而区试增产率不进入，因此其品种在品质上占优、在相对增产率上落后"。B 的副标题是 *Breeding for the Mill or for the Yield Trial?*，D 的备选副标题是 *Breeding for the mill, not for the trial* ——**两份提案想出了同一个标题**。它们的主分析层（n=1,353 vs n=1,349）、固定效应设定、核心因变量、甚至荃银识别规则都相同。这不是两篇论文，这是同一篇论文的两个草稿。若分别投出，任何一家期刊的 similarity check 都会命中，后果是两篇同时被撤。

**合并方案：以 B 为骨架。**

保留 B 的：
- 制度背景与概念框架（第 2–3 节），B 的 H1/H2/H3 命题体系比 D 的 π 函数形式化更适合农经读者；
- **H3 的表述**（一体化企业对齐的是"可认证、可加工、可收储"的品质，而非消费端外观溢价）——这是 B 独有的、四份提案里最精巧的一个发现：官方定等 logit 显示垩白度与整精米率被奖励而长宽比不被奖励（p=0.234），恰好与荃银的性状组合吻合。这一条应当成为合并后论文的**题目来源与摘要第一句**；
- 会计分解（§7.7）与四组主体设计；
- CAER / JIA / Agriculture 的三级期刊路径。

移植 D 的：
- **M4 堆叠式单参数检验 λ = +0.570 SD（p<0.0001）**——把机制压成一个数，直接替换 B 目前作为动态证据的那个**零结果事件研究**。B 现在的叙事是"我有一个稳健的截面关联 + 一个失败的事件研究"，这在审稿人读来是心虚的；换成 λ 之后叙事变成"我有一个单参数的机制检验 + 一个诚实报告的功效不足的时间检验"，气质完全不同；
- **H4 安慰剂性状体系 + 剔除荃银的样外复制**——B 目前只有块置换与省审复制，缺少"安慰剂性状"这一层。D 的发现（荃银单独看安慰剂失败=种质血缘签名，合并一体化组安慰剂通过）虽然难看，但**正是回应"你捕捉的是血缘不是激励"这一必问问题的唯一材料**，必须原样写进合并稿；
- **H3 反面检验**（科研单位在每一个收益相关性状上符号相反：产量 +6.77 kg/亩、整精米率 −1.65 pp、垩白度 +0.93 pp）——这是区分"收益函数解释"与"企业资源更多解释"的最有力证据，B 的四组设计里有这个结构但没有把它作为独立论证写出来。

**明确舍弃 D 的：**
- §8.7 的"2,150 万 vs −1,280 万"价值分解（软文风险，见 2.3）；
- D 的 π 函数形式化（对农经读者是常识，对作物科学读者是噪音，写成一段文字即可）；
- D 的 Fig.7。

**合并后的自评：** novelty 约 7、feasibility 8、fit 7、rigor 7、generality 6 → total ≈ **7.15**。仍低于 C 与 A，原因是结构性的：Xie23 已经用同一家企业做过订单农业、Su22 已经做过农企多元化与创新，而合并稿的因果身份最多只能到"目标函数一致性"。**这不是写作能改善的，需要数据：把 n=1 真正变成 5–6 家的连续一体化强度面板（D 的 R3(a)(b)(c)），并跑通"改革后 × 一体化"三重差分（D 的 R7）。这两件事做完，合并稿的 rigor 与 generality 各能涨 1–2 分，total 可达 7.8–8.0，那时才值得与 A 争第二篇的位置。在做完之前，不建议投出。**
