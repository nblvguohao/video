# 主会话独立复算（2026-09-14）——通道效应的分通道检验

目的：统计评审指出提案 C 把"绿色通道"（2017，n=88）与"联合体"（2019–2022，n=692）合并为单一"新通道"处理，而两者在时间上不重叠、且自报增产率的符号相反。故我在**全国审样本**（未限于提案 C 所用的两大籼稻试验组）上分别估计。

设定：结果 ~ 通道 + 年份 + 试验组 + 对照 + 制种体系，按试验组聚类。
数据：`evidence/data/analysis_rice_channel.pkl`（6,734 条；Unified 5,816 / Consortium 795 / Green 123）。

## 结果三：合并"任一新通道" vs 统一试验，2017–2022（n=2,650）
整精米率 −1.260（p=0.006）；垩白度 +1.260（p=0.032）；载明等级 −0.133（p=0.049）；**达一/二级 −0.133（p<0.001）**；自测增产率 +0.692（p=0.089）；生育期 −0.636（p=0.010）。

## 结论（决定最终框架）
1. **稳健成立**：经自组织试验进入市场的品种，其**第三方统一测定**的稻米品质系统更差——整精米率更低、垩白度更高、达到国家/行业米质等级（尤其一、二级）的概率更低。该结论在联合体、绿色通道、合并三种设定下方向一致，且在最严的"达一/二级"指标上 p<0.001。
2. **仅为提示性、不可作为主结论**：自报增产率更高这一半。联合体臂 +0.800（p=0.071）、合并 +0.692（p=0.089）方向一致但不显著；2017 绿色通道臂符号相反（n=101）。
3. **与叙事冲突的一项**：2017 年绿色通道品种的白叶枯病级反而更好（−0.457, p=0.002），须在正文如实报告。
4. 因此最终论文的主命题应表述为**"第三方测定品质的系统性缺口"**，把"自报产量优势"降级为提示性证据与机制讨论，而非并列的主结果。这与统计评审的判断一致。

（技术说明：模型中同时纳入试验组与对照会产生共线，正式分析须改为对照嵌套于试验组、或仅保留其一。）
