## 2. 核心数据集：national_rice_parsed.csv
- 7,883 条审定记录（国审 2,396、省审 4,780、无编号 707），审定年份 1999–2025。
- 2005 年后**国审**行的性状字段覆盖率：两年区试亩产 95.6%、生育期 99.3%、株高 99.2%、千粒重 99.5%、整精米率 99.0%、垩白度 97.7%、直链淀粉 96.8%、增产率 79.1%、穗颈瘟损失率最高级 65.7%、白叶枯 59.7%、褐飞虱 72.0%、米质等级 56.8%、稻瘟病综合指数仅 14.7%。

## 3. 育种主体（企业 vs 科研单位）归属的结构性缺口
用 申请者/选育单位/育种者 字段分类 2,396 条国审记录：企业 805、科研单位 507、联合 104、**无机构信息 980**。
按年份看，缺口高度集中：

| 年份 | enterprise | joint | public | unknown |
|---|---|---|---|---|
| 2016 | 0 | 0 | 0 | 66 |
| 2017 | 1 | 0 | 0 | 174 |
| 2018 | 1 | 0 | 0 | 233 |
| 2021 | 0 | 0 | 0 | 431 |

即 **2016、2017、2018、2021 四年的国审记录缺失全部机构字段**（合计 904 条）。这直接解释了为何解析数据中荃银在 2016/2017/2021 年为 0 条——不是没有品种，而是机构字段缺失导致无法识别（公司年报显示 2021 年国审水稻 92 个）。

### 对研究设计的约束（必须遵守）
- 性状轨迹分析（产量/品质/抗性/生育期）可用全部 2005–2024 国审样本（n≈2,390），不受机构缺口影响。
- 育种主体对比分析只能用有机构信息的年份（2005–2015、2019–2020、2022–2024，n≈1,416），并须明确报告缺失年份及其非随机性；或先用 WebSearch 补采 2016/2017/2018/2021 的申请者字段（904 条，需并行代理）。
- 荃银品种的完整识别同样受此影响：须用 WebSearch 按公司年报品种名单补采上述四年。
- 2025 年国审记录仅 2 条，2025 年分析只能用公司/行业层面汇总数据。
