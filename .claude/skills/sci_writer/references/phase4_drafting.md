# Phase 4 详解：撰写

## 章节契约先于段落

`02_research_route.md` 里应该已经为每一节定义了契约：purpose（这节要做什么）、allowed claims（可以主张什么）、forbidden claims（不能主张什么，尤其是探索阶段已标注"证据不支持"的说法）、inputs（这节可以引用哪些证据文件/图表/结果文件）。写作前把契约摆在最前面读一遍——它的作用是防止"结果部分开始下因果结论""讨论部分突然冒出一个没有出处的新数字"这类最常见的写作滑坡。

## 并行分节撰写

按契约把 Introduction / Methods / Results / Discussion / Title-Abstract-Keywords 分给独立的撰写代理并行处理，各自只读自己需要的证据文件与结果文件（不是全部证据），减少互相干扰也减少上下文负担。

## 写作规范

- **先立论点**：每段首句是主张句，随后给证据（数字+图表/引用），末句给边界或含义。不写"过渡句式"的空话。
- **主张不得超出证据**：探索阶段标注过"不能支持"的说法禁止出现在正文；用与证据强度匹配的措辞（"suggests / is consistent with / indicates"分级使用，不要都用最强的"proves/demonstrates"）。
- **每个数字必须可追溯**：正文中的任何数字都应该能在表格、结果文件或证据索引里找到出处；图表编号连续，且正文首次提及顺序与编号顺序一致。
- **负面事实如实呈现**：案例主体的失败、争议、监管处罚等不能被稀释或回避，这既是诚信要求也是"不像宣传"的关键。
- **术语与命名统一**：案例主体名称、产品/记录名称第一次出现给出完整名称+缩写，之后统一用缩写；避免同一实体出现多种表述方式。
- **避免 AI 腔套话**：不用空洞的高级词堆砌（如"delve, landscape, underscore, pivotal, in the realm of"这类），句子避免过长，术语首次出现给定义。

## 整合

统一图表编号、术语、数字格式（千分位、小数位、单位）；收集所有引用标记，去重后统一编号或按作者-年份格式排列（按目标期刊格式规范）；生成图表清单（编号、标题、文件、首次引用位置）；记录整合过程中发现的不一致（不要悄悄改掉，要在日志里记录）。

## 参考文献核验（不要跳过）

整合完成后，独立派一名"参考文献核验员"对每条引用逐条核实：作者、年份、题名、期刊、卷期页、DOI 是否一致，用学术检索工具多源交叉验证（同一条引用至少两个独立来源）。核实不了的文献**从正文移除引用**并在日志说明，绝不允许带着未核实的文献进入下一阶段——这是审稿人和期刊编辑最容易抓到的硬伤，也是最容易被写作过程悄悄引入的问题（起草时随手编一个"看起来应该存在"的引用）。
