# 中文参考文献的检索与核验

目标：20~26 条**真实、可查证**的中文文献，按 GB/T 7714—2015 著录，字段与原文一致。

## 环境限制：知网、万方、维普、百度学术通常不可访问

这类会话的出站网络多受策略限制，CNKI、万方、维普、百度学术、Google Scholar 往往
直接被网关拒绝（403），WebFetch 对期刊官网也常被挡。**先花一分钟探测，别反复撞墙**：

```bash
for d in www.cnki.net d.wanfangdata.com.cn xueshu.baidu.com www.plantnutrifert.org; do
  echo "$d -> $(curl -sS -o /dev/null -m 10 -w '%{http_code}' "https://$d/" 2>&1 | tail -c 30)"
done
```

实际可用的通道通常只有 **WebSearch**。它的结果摘要里经常直接带出完整著录，够用，
但要换着法子问。学术类 MCP（Consensus、Elicit、Scholar Gateway）以英文文献为主，
对中文农业期刊覆盖很差，不必指望。

## 检索策略

一条文献至少换 3~4 种检索式，命中率差别很大：

1. 加引号的精确题名 + 第一作者
2. 题名关键词 + 刊名 + 年份 + 卷(期) + 起始页（把你已知的字段全堆上去，搜索引擎
   常会返回带完整著录的页面摘要）
3. 第一作者 + 刊名
4. DOI 或文章编号

**文章编号是好东西**。中文期刊的文章编号形如 `1007-5739(2016)04-0009-02`，直接编码了
年份、期号、起始页和页数——拿到它就等于拿到了年、期、页。

**引文列表是二手但可靠的来源**。手头若有同类论文的 PDF，其参考文献表里常有你要的
条目。注意照抄时不要把原有的"等"弄丢。

## 收录标准

只收录你在检索结果里**亲眼看到**书目信息的文献，至少要看到：题名 + 第一作者 +
刊名 + 年份。卷、期、页、DOI 只在看到时才填，**没看到就留空，绝不凭记忆补全**。

每条记下证据 URL 和逐字摘录的证据片段，便于复核。

优先：中文期刊论文[J]、国家/行业标准[S]、部委技术规范。不收学位论文、会议摘要、
新闻、百科、公众号。优先 2015 年以后，经典方法学文献可更早。

## 作者人数：最容易出系统性错误的地方

GB/T 7714 要求作者超过 3 位时列前 3 位后加"等"。而检索结果的摘要**经常只显示前 3 位
就截断**，照抄就会漏掉"等"——这是与原文不符的著录错误，不是排版问题。

所以每条都要单独确认真实作者数。有效办法：

- 搜"题名 + 前 3 位作者姓名"，结果摘要常会列出完整名单
- 期刊官网 PDF 预览页的标题行常带全部作者（如
  `王姣琳1,2，徐新朋2*，杨兰芳1*，黄晓萌1,2，何 萍2，仇少君2，赵士诚2`）

`scripts/make_refs.js` 按结构化字段自动加"等"，所以**在 refs_data.json 里填完整
作者名单**，不要自己截断到 3 位。

## 无法核实的条目怎么办

若关键字段（尤其年份）多次检索仍无法确认：

1. 首选**删除该条，改引可核实的同类文献**。带占位符的著录不具备投稿条件。
2. 若该文是用户提供的原始资料、内容上不可替代，可暂留并用黄色高亮标出待核字段，
   同时明确告诉用户需要他用知网补齐——但要一并给出可替换的候选。

绝不为了凑数而编造年、卷、期、页。

## 配比建议

一篇省级农业期刊的试验报告，20~26 条文献，大致：

| 类别 | 条数 | 说明 |
|---|---|---|
| 测土配方施肥背景与规范 | 2~3 | 含 1 条部委规范或行业标准 |
| "3414"方法学与效应模型 | 2~3 | 模型拟合、典型性、建模策略 |
| 本省同类试验 | 4~5 | 体现区域针对性，审稿人很看重 |
| 省外同类试验 | 3~4 | 优先同一稻区 |
| 作物营养与产量构成 | 3~4 | 支撑讨论中的机理解释 |
| 土壤养分丰缺指标 | 1~2 | |
| 化肥减量增效、肥料利用率 | 2~3 | |
| 品种、区域生产背景 | 1~2 | |

2015 年以后的应占一半以上。同一作者或同一县市的同类试验最多 2 条。

## 引用与论断必须对得上

写完后逐处检查每个 `[[key]]` 所在的句子，该文献是否真能支撑这个论断。常见错误：

- 用"肥料利用率现状"的文献去支撑"磷素累积的环境风险"
- 用"双季稻磷钾用量与密度组合"的文献去支撑"砂壤土阳离子交换量低、钾素易淋失"的
  土壤化学机理
- 引言里一句话堆 6 条文献，而其中方法学价值最高的两条在正文再没出现

对不上就改写句子去迁就文献，或换一条能支撑的文献。宁可让论断弱一点，也不要让引用
与内容脱节——这是审稿人最容易抓住的硬伤。
