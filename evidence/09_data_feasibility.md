### 1.3 第二轮（改写检索式）——增量为零

对 5 条失败品种改用 `"<品种名>" 水稻 品种 育种者 申请者` / `"<品种名>" 水稻` / 纯编号批量检索三种写法各再试一次，**5 条全部仍然失败，增量 = 0**。

**结论 1-A（关键机理）**：命中与否**不取决于检索式，而取决于该品种的 ricedata.cn 品种详情页是否被搜索引擎索引**。10 条中，5 条成功者的结果列表里全部出现了对应的 `ricedata.cn/variety/varis/<id>.htm`；5 条失败者一个也没有。改写查询无法创造索引。

**结论 1-B**：批量检索（一次查 3 个审定编号）完全无效 —— 返回的是无关的省级目录 PDF，零条命中。**机构补采只能 1 品种 = 1 次检索。**

### 1.4 风险：摘要串味与错配（已实测到 2 例）

- 检索「安优美占 国审稻20186109」时，摘要返回的是**荃优华占**的申请者/育种者，并以肯定语气陈述。若不核对品种名即入库，会产生虚假的「荃银高科品种」记录 —— 对本论文（以荃银为主线）是**方向性偏倚**。
- 检索「瑞两优1053 国审稻20210299」时，摘要给出的机构名可信，但同时标注该品种的编号是「国审稻20200245」，与目标编号不符。同名品种多编号（多生态区分别审定）在国审体系中普遍存在。

### 1.6 替代路径：品种名前缀启发式识别荃银品种（已量化验证）

在 `applicant` 非空的 1,485 条国审记录上，用正则 `^荃` 预测 `is_winall`：

- **精确率 Precision = 1.000**（TP=79，FP=0）
- **召回率 Recall = 0.568**（FN=60）
- 漏判集中在早期品种名：徽两优898、徽两优882、新华两优9号、新两优343/223/917/901/106、两优8106、两优383、新优188 等（2005–2015 年荃银尚未统一用「荃」字冠名）

在全部 2,396 条国审记录上，`^荃` 命中 165 条；与 `is_winall=True` 的 139 条取并集得 **203 个可识别荃银国审品种**（vs 仅用 applicant 字段的 139 个，**+46%**）。

**结论 1-D**：`^荃` 前缀规则是**零误报**的荃银识别器，可在机构字段缺失的 2016/2017/2018/2021 四年直接使用（这四年荃银已全面采用「荃」字冠名，见 2016 年起 quan-prefix 计数 1→15→23→56）。这把「识别荃银品种」的成本从 906 次检索降到 **0 次**，代价是牺牲 2005–2015 年约 43% 的早期荃银品种（这部分年份的 applicant 字段本来就齐全，可直接用字段补上）。**这是本轮最有价值的成本节约发现。**

### 1.7 附带发现：荃银的子公司在缺失年份中现身

探针 #1「欣两优晚一号」的申请者是**安徽荃银欣隆种业有限公司**——荃银控股子公司，但品种名不带「荃」字。说明：
- 荃银系的品种归属需要一个**子公司名单**（荃银欣隆、荃银禾丰、荃银超大、湖北荃银高科、荃银农业高科技研究所 等，已在本地 applicant 字段中出现）；
- 仅靠「荃」字前缀会漏掉子公司用非「荃」字命名的品种（如「创两优丝苗」，申请者=安徽荃银超大种业有限公司，本轮检索中偶遇）。

### 2.2 品种名单：**无法拿到完整清单**（核心失败项）

三次检索（含一次专门要求枚举的检索「荃银高科 57个新品种国家审定 名单 … 品种名称列表」）只能拿到**示例性名称**，从未拿到完整 N 个名字：

- 2025 年（52 个水稻）实得 5 个：**荃盛优822、荃优535、荃两优686**（自主选育）、**庐州占、银两优晶占**（合作选育）；玉米 5 个全得（荃研686/206/616、荃科789/666）。**水稻名单获取率 5/52 ≈ 9.6%。**
- 2024 年（59 个水稻）实得 1 个：**银两优392**（另有摘要称 2024 年有 16 个杂交水稻实现多区域国审）。**获取率 1/59 ≈ 1.7%。**
- 2023 年（64 个水稻）实得 0 个。**获取率 0%。**

原因：完整名单只存在于两类载体中——①农业农村部公告附件 PDF（`zys.moa.gov.cn`，被拦截）；②荃银公司公告 PDF（`chinext.zqrb.cn` / `notice.10jqka.com.cn` / `static.cninfo.com.cn`，全部被拦截）。搜索引擎摘要器**不会枚举长列表**，只会给出「包括 A、B、C 等」。

**结论 2-A**：**2023–2025 年荃银品种名单在本环境不可得。** 这是一个**无法用更多检索次数解决**的缺口（增加检索只会重复拿到同样 3–5 个示例名）。

**结论 4-B**：`read_pdfs` **可以可靠地从 OA PDF 正文中抽取数值表格**，精度足以支撑 meta 分析式的对照。

- **不能拿**：任何 .xlsx/.docx 补充数据文件 → **无法把 Fen17 的 635 条并入本项目样本**。

| **获取工作量** | **0 次新增检索**（全部字段已在本地 CSV 中）。仅需 1 次 GitHub raw 下载验证上游 `rice_extracted_fields.csv`（§3.3-C） |
| **风险与偏差** | ①字段覆盖不均：稻瘟病综合指数仅 14.7%、米质等级 56.8%、白叶枯 59.7% → 抗性与米质等级分析样本骤减，且缺失非随机（早期公告不报该字段）；②`^荃` 规则在 2005–2015 年召回仅 0.568 → 早期荃银品种被低估（可用该期完整的 applicant 字段补上，无成本）；③**与 Lu24 / Han24 高度重叠，2 区创新性不足**；④对照品种(CK)随年份更换，增产率不可跨年直接比较，须以 CK 为随机效应或改用绝对产量 |

### 方案 B —— 「育种主体异质性：企业 vs 科研单位 vs 联合」（**推荐主方案**）

| 项 | 内容 |
|---|---|
| **核心问题** | 在 2000 年《种子法》与 2016 年修订（审定绿色通道、企业自主试验）之后，**企业育成品种与科研单位育成品种在产量/品质/抗性/生育期上是否系统性不同**；荃银高科作为「企业育种崛起」的代表性案例的微观路径 |
| **样本量** | **国审 + 省审合并，2005–2024，applicant 非空且含生育期与产量：n = 2,981**（国审 1,332 + 省审 1,649）。<br>若只用国审：applicant 非空 n = 1,346（含产量 1,332）。<br>**关键增量**：省审 2005–2024 共 4,662 条中 **3,701 条（79.4%）有 applicant 字段** —— 省审子集的机构覆盖率远高于国审，主要分布在粤(692)、赣(635)、桂(414)、湘(364)、浙(362)、闽(305)、皖(219)、黑(205) |
| **变量清单** | 同 A，外加：育种主体类别（enterprise / public / joint / unknown）、审定层级（国审/省审）、审定省份、企业是否上市、是否荃银系（含子公司：荃银欣隆、荃银禾丰、荃银超大、湖北荃银等）、政策期虚拟变量（2000 种子法前后、2016 修订前后） |
| **获取工作量** | **主体分析 0 次新增检索**（用已有 applicant 字段）。<br>可选增强：①下载并解析上游 `rice_extracted_fields.csv`（**1 次**，可能一次性补回大量机构字段）；②对 2016/2017/2018/2021 的 906 条做定向补采（**906 次 WebSearch ≈ 5 个会话**，预期补齐 450 条，需人工核验约 180 条） |
| **风险与偏差** | ①**机构缺口的非随机性是头号威胁**：2016/2017/2018/2021 四年国审机构字段 100% 缺失，恰好覆盖 2016 年《种子法》修订后的关键窗口 —— 若不补采，**恰恰无法观测政策冲击后的头 3 年**；②补采本身有选择性偏倚（ricedata 索引覆盖可能与品种知名度正相关 → 大企业大品种更易补上）；③省审与国审的试验设计、对照品种、审定标准不同，合并须用层级模型并加审定层级固定效应；④「申请者 ≠ 实际育种者」，部分品种由科研单位育成后转让企业申请，会把 public 误记为 enterprise → 建议同时用 `育种者` 字段做稳健性检验 |

### 方案 C —— 「荃银高科单案例深描 + 行业背景」（叙事型 / 数据要求最低）

| 项 | 内容 |
|---|---|
| **核心问题** | 以荃银高科 2005–2025 的品种组合演化、商业化产出与产业地位为主线，刻画「中国种业企业如何从跟随者成长为国审品种数量第一梯队」 |
| **样本量** | 荃银可识别品种 **203 个国审**（`^荃` 前缀 165 ∪ applicant 命中 139）+ 66 个省审 ≈ **269 个品种**；公司年度面板 2015–2025（11 年 × 约 12 个指标，已在 `company_panel.csv`）；行业面板：杂交稻制种面积/种子供需 2015–2025（需 11–22 次检索补齐） |
| **变量清单** | 品种侧：同 A（限荃银子集）+ 亲本（荃9311A、荃211S 等不育系家族）、系列归属（荃优/荃两优/银两优/徽两优/新两优）、申请子公司。公司侧：营收、归母净利、水稻种子收入与毛利率、各作物销量与增速、出口量与海外占比、推广面积、研发投入、年度国审品种数（2021:92、2023:64、2024:59、2025:52 水稻）。行业侧：制种面积、新产种子量、有效库存、供需比、CR5（2019: 9.6% → 2023: 19.2%）、全国年度国审稻数（2023:409、2024:405） |
| **获取工作量** | **11–22 次 WebSearch**（重建 2015–2025 制种面积/供需序列，每年定向 1–2 次）+ **约 10 次**（补公司缺失年份的销量/出口点值）= **约 25–35 次**，1 个会话内可完成 |
| **风险与偏差** | ①**幸存者/冠军偏倚最严重**：只看荃银这一家成功企业，无法支撑任何因果推断，只能做描述性案例；②近三年（2023–2025）荃银品种名单不可得（§2.2），品种侧只能停在 2022；③行业数字来自媒体转述的二手摘要，同一指标常有多个口径（如优质稻占比 57% vs 62.0%），须逐条标注来源与口径；④年报数字未经原始 PDF 核对（PDF 全部被拦截），存在转述误差 |

### 三案比较与推荐

| | A | **B（推荐）** | C |
|---|---|---|---|
| 样本量 | 2,056–2,255 | **2,981（合并）/ 1,346（仅国审）** | 269 品种 + 11 年公司面板 |
| 新增检索成本 | 0–1 次 | **0 次（基础版）/ 907 次（完整版）** | 25–35 次 |
| 2 区创新性 | 低（与 Lu24/Han24 撞车） | **高（育种主体异质性尚无人做）** | 中（单案例，需强理论包装） |
| 主要风险 | 撞车 | **机构缺口非随机** | 幸存者偏倚 |

**推荐组合：以 B 为主体 + A 作为背景轨迹 + C 作为机制章节**。即：用 B 的 2,981 条样本回答「企业 vs 科研单位」的主问题，用 A 的全样本轨迹提供演变背景，用 C 的荃银案例把统计结果落到一个可讲述的企业机制上。这样**基础版 0 次新增检索即可成稿**，补采（907 次）只作为提升 2016–2021 窗口完整性的可选增强。
