# 荃银高科为主线的农业论文项目（目标：中科院二区农林科学类期刊）

目录结构：
- `evidence/`   信息收集：公司公告/年报、新闻、科研项目、审定品种、学术文献（结构化证据库）
- `plan/`       主题凝炼、创新点、研究路线、目标期刊评估与格式规范
- `manuscript/` 论文正文（按目标期刊格式）
- `figures/`    图表与生成脚本输出
- `scripts/`    数据整理、图表绘制、参考文献核验脚本
- `submission/` 投稿包（cover letter、highlights、格式检查清单、版本对照）

工作流：信息收集 → 主题/创新点 → 期刊评估 → 撰写 → 投稿前审查。
