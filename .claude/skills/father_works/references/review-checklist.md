# 六视角评审清单

出稿后按六个视角过一遍。下列条目是从真实评审中反复出现的问题里提炼的，按视角分组，
逐条对照原始数据核实——**核实，不是照单全收**，评审意见本身也可能不成立。

评审值得用子代理并行跑（六个视角各一个），再对每条意见做一次对抗式核验。但即使
独自过一遍这张清单，也能挡掉大部分退修。

## 一、数据核查

- [ ] 正文、摘要、结论里的**每一个数字**都能在 data.json 里找到对应值。写个脚本逐条
      比对，不要凭眼看。
- [ ] 表格每个单元格与 data.json 一致；表格数值与正文叙述一致。
- [ ] "某处理各项性状均最低/最高"这类全称断言，逐项验证。产量最低的处理，其结实率和
      千粒重往往**不是**最低（高氮处理才是），这个错几乎每次都出现。
- [ ] 描述某因素"随用量增加而持续增加"时，检查是否在某水平后已经持平。相邻两水平
      数值相同却写成"增至"，会掩盖平台效应。
- [ ] 日期与原始记录一致。测产日、收获日、施药日不要合并或改写。
- [ ] 电子资源的引用日期不早于试验结束日期，也不晚于成稿日期。

## 二、统计

- [ ] 未设重复却使用了"显著"——检查全文。只有相关分析和回归检验可以谈显著性。
- [ ] 报告 R² 时是否同时给了校正 R²（三元二次方程残差自由度只有 4）。
- [ ] 单因素方程的 F、P 是否如实报告。4 点拟合 3 参数、残差自由度为 1，基本都不显著，
      要说明方程只作趋势描述。
- [ ] 相关分析是否给出 n、df 与临界值。
- [ ] 由相关推因果——"决定产量的主要因素"应改为"与产量关系最密切"。
- [ ] 模型外推值（最高产量施肥量、对应产量）是否都标注了"超出试验设计范围"。只标
      施肥量不标产量，读者会误以为那个产量可达。
- [ ] "典型性"只对二次型方程适用，不要给线性或线性加平台模型填"典型"。
- [ ] 线性加平台的拐点精度。平台段只有一个观测点时，报"约 280"比报"282.0"诚实。
- [ ] 方法里声明了的东西，结果里要出现。声明"最佳经济施肥量按边际产值等于边际成本
      求得"却全文未给该值，属方法与结果不呼应。
- [ ] 分级临界与基数敏感性是否交代（见 analysis-methods.md）。

## 三、期刊格式

- [ ] 题名 ≤20 字；关键词 3~8 个；中图分类号与文献标识码齐全。
- [ ] 摘要四要素结构完整，中英文一一对应，篇幅 300~450 字。
- [ ] 章节编号规范（1、1.1、1.1.1），标题层级视觉权重递减。
- [ ] 三线表，表题在上、表注在下；表头含量名称与单位；有量词。
- [ ] 量符号斜体（*y*、*x*、*R*²、*r*、*F*、*P*、*n*）；下标真下标。
- [ ] 负号用数学减号 U+2212，不是全角连接号。
- [ ] 数字与单位间空格；中文全角标点、英文半角标点。
- [ ] 图的单位写法与表格一致（都用 kg/hm² 或都用 kg·hm⁻²，不要混）。
- [ ] 连续引用序号用短横线连接。
- [ ] 全文字体纯黑，无彩色。
- [ ] 渲染成 PDF 逐页看一遍。重点看：表格是否跨页断裂、公式是否把整行拉伸得字距过大、
      参考文献两端对齐是否把中文责任者拉出大空隙。

## 四、文献引用

- [ ] 每处引用的文献确能支撑该句论断（详见 reference-verification.md）。
- [ ] 作者超 3 位的都加了"等"，且以原文实际人数为准。
- [ ] 每条著录字段完整；无法核实的条目已删除或明确标出。
- [ ] 正文引用序号按首次出现顺序，与文后一一对应；无只列不引、无只引不列。
- [ ] 正文提到的标准/文献名称与文后著录名称一致（《技术规范》与《技术规程》是两份
      不同文件，别混）。
- [ ] 对他人结果的转述与原文一致，不要拔高。

## 五、写作

- [ ] 术语全文统一（有效穗数/有效穗、每穗总粒数/总粒数，选一种贯穿）。
- [ ] 讨论与结果对应，不引入结果里没有的内容。
- [ ] 无过度推断：单点单年试验不要外推到整个大区。
- [ ] 推荐方案的处理组合内部自洽——别把缺素区处理写进推荐基础。
- [ ] 英文摘要语法与专业表达准确。"a plateau at 282 kg/hm²"会被读成平台产量是 282，
      应写 "the plateau … beginning at an N rate of 282 kg/hm²"。
- [ ] 句子不要过长。一段里塞进三四个长公式会把版面拉伸得很难看，按因素拆段更好读。

## 六、模拟审稿人

站在退修意见的角度问自己：

- [ ] 试验设计的局限有没有如实交代？单年、单点、不设重复、2 水平偏高，都要写明。
- [ ] 2 水平是否明显高于当地常规推荐量？若是，磷钾在试验范围内不出现拐点很可能是
      设计所致而非土壤真实响应，必须说明，否则推荐量站不住。
- [ ] 推荐量与自身数据是否矛盾？贡献率只有 5% 的养分却推荐最高档用量，是最可能被
      直接退修的地方。
- [ ] 关键数据有没有缺项？测土配方施肥类论文缺土壤养分实测值，论据链是断的。
- [ ] "纯收益"是否名实相符（见 analysis-methods.md）。
- [ ] 摘要与结论的确定性措辞是否超出证据强度？加"初步""在…条件下"这类限定。
- [ ] 虚假精度：产量报到 0.1 kg/hm² 而实测分辨率是 33 kg/hm²。同类期刊惯例是保留
      1 位小数，可以照惯例，但讨论里要说明分辨率。
